# AI Helpdesk frontend

The React, TypeScript, and Vite interface for AI Helpdesk. It provides authentication, protected navigation, dashboard metrics, ticket workflows, PDF document management, background-status polling, and the RAG question interface.

See the [project README](../README.md) for complete architecture, setup, testing, and Docker instructions.

```bash
cp .env.example .env
npm ci
npm run dev
```

Quality checks:

```bash
npm run lint
npm test
npm run build
```
